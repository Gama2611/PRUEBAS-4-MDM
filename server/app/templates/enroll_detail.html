Cómo activar cada tablet

1
Restablece la tablet de fábricaAjustes › Sobre la tablet › Restablecer datos de fábrica. Si es nueva, sólo enciéndela.
2
Toca 6 veces la pantalla de bienvenidaEn la primera pantalla (la del idioma), en un espacio vacío y siempre en el mismo punto. Se abre el lector de QR.
3
Escanea este códigoSi pide Wi-Fi, elige la MISMA red en la que está esta PC. Acepta las pantallas de «dispositivo administrado». Mira abajo «¿Qué pasó en la activación?».

Cómo leer esta lista

No aparece nada después de escanear → la tablet no llega a esta PC. En orden: (1) Firewall: ejecuta ABRIR_FIREWALL.bat; (2) la tablet y la PC deben estar en la misma red (la Wi-Fi de invitados o con «aislamiento de clientes» no sirve); (3) revisa la «Dirección que va dentro del QR»; (4) si el QR trae Wi-Fi, prueba con «Usar QR sin Wi-Fi» y conéctala a mano.

«La descarga del agente se cortó» → señal débil: acerca la tablet al router e intenta de nuevo.

«Agente descargado completo» pero la tablet igual falla → la red está bien; el problema es el APK del agente. Sube el APK release firmado más reciente de GitHub Actions (no el «debug») y genera el QR otra vez.

«Tablet activada» → todo bien. «El MDM rechazó la activación» → el código venció o se agotó: genera uno nuevo.

Prueba la red con un celular

Conecta un celular al mismo Wi-Fi que usarán las tablets y escanea este código con su cámara.

Si se abre una página con ✅ Conexión correcta, la red y el Firewall están bien.

Si no abre, el problema es de red: Firewall, red distinta o Wi-Fi de invitados.

Instalar el agente en la PC

Copia la carpeta agent-pc a la PC y ejecuta, como Administrador:

Windows (PowerShell)

powershell -ExecutionPolicy Bypass -File install_windows.ps1 -Server {{ public_url }} -Token {{ et.token }}

Linux

python3 agent.py enroll --server {{ public_url }} --token {{ et.token }}
python3 agent.py run
